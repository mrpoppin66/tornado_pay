# TornadoPay MVP

Первый рабочий каркас Telegram-бота для Railway.

Внутри:
- главное меню;
- профиль;
- тестовый баланс;
- каталог услуг;
- создание заявок;
- история заявок;
- Postgres (данные переживают редеплой).

### Railway
1. Загрузите проект.
2. Railway автоматически обнаружит `Dockerfile`.
3. В том же проекте добавьте плагин **Postgres** (New → Database → PostgreSQL) — Railway сам создаст переменную `DATABASE_URL` и подставит её сервису бота автоматически (если сервисы в одном проекте).
4. В Variables добавьте `BOT_TOKEN` — токен BotFather.
5. Deploy.

Если раньше был подключён Railway Volume под SQLite — его можно отключить, он больше не используется.

Токены CryptoBot/xRocket в этот архив не входят. Их подключим отдельным этапом.

Следующий этап: реальные суммы, CryptoBot/xRocket, комиссия, исполнители, распределение заявок и админка.
