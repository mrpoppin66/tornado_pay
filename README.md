# TornadoPay MVP

Telegram-бот маркетплейса услуг с оплатой в криптовалюте (деплой на Railway).

Внутри:
- главное меню;
- профиль и баланс;
- каталог услуг;
- создание заявок с конвертацией RUB → USDT и комиссиями;
- история заявок;
- админ-панель (заявки, услуги, пользователи, статистика);
- Postgres — данные переживают редеплой;
- курс USDT/RUB с CoinGecko (обновление каждые 5 минут).

### Railway
1. Загрузите проект.
2. Railway автоматически обнаружит `Dockerfile`.
3. В том же проекте добавьте плагин **Postgres** (New → Database → PostgreSQL) — Railway сам создаст переменную `DATABASE_URL` и подставит её сервису бота автоматически (если сервисы в одном проекте).
4. В Variables добавьте `BOT_TOKEN` — токен BotFather, и `ADMIN_ID` — ваш Telegram ID (можно несколько через запятую).
5. Deploy.

Если раньше был подключён Railway Volume под SQLite — его можно отключить, он больше не используется.

### Что исправлено в этой версии
- убраны `DROP TABLE` при старте: данные больше не стираются при редеплое;
- добавлены безопасные миграции (автодобавление недостающих колонок);
- курс заявки фиксируется один раз и не расходится между показом клиенту и записью в БД;
- `aiohttp` зафиксирован в requirements.txt.

Токены CryptoBot/xRocket подключаются отдельным этапом.

Следующий этап: CryptoBot/xRocket-оплата, регистрация исполнителей, распределение заявок.
