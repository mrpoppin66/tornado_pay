# TornadoPay v21

Обновление: для услуги **«Карта под оплату»** бот больше не запрашивает и не сохраняет данные карты исполнителя.

Сценарий:
1. Пользователь выбирает «Карта под оплату».
2. Вводит сумму.
3. Вводит комментарий, что оплачивается.
4. Заявка создаётся и становится доступной исполнителям.
5. Исполнитель берёт заявку.
6. Бот сообщает исполнителю, что данные карты нужно отправить пользователю через анонимный чат.
7. Пользователь и исполнитель общаются через чат.
8. Исполнитель отмечает выполнение, пользователь подтверждает.

Старые поля `executor_card_reference` и `executor_card_encrypted` в БД намеренно не удаляются для совместимости со старыми версиями. Новая версия их не заполняет.

Для остальных услуг сценарий не изменён.
